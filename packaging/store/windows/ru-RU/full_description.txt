Obxodka — современный высокопроизводительный VPN-клиент на платформе C# (.NET), спроектированный для обеспечения конфиденциальности, высокой скорости и стабильного сетевого подключения.

Приложение обеспечивает минимальные задержки соединения, отсутствие потери пакетов и лаконичный интерфейс в стиле Fluent Design для Windows 10 и Windows 11.


ТЕХНИЧЕСКИЕ ОСОБЕННОСТИ И АРХИТЕКТУРА:

1. Двусторонняя аутентификация mTLS и шифрование AES-256-GCM
Клиент использует Mutual TLS (mTLS) с индивидуальными клиентскими сертификатами стандарта X.509 для строгой проверки подлинности на транспортном уровне (L4). Весь трафик шифруется алгоритмом AES-256-GCM. Закрытые ключи хранятся в защищенном системном хранилище ОС.

2. Протокол OBXODKA-STREAM и защита от фильтрации DPI
Трафик инкапсулируется в оптимизированный дуплексный поток HTTP/2 поверх TLS 1.3 с динамической маскировкой под легитимный веб-трафик. Микросегментация пакетов (DpiBypassStream) и динамический пул доверенных SNI обеспечивают устойчивость туннеля к системам глубокого анализа пакетов (DPI/ТСПУ).

3. Архитектура Dual-Ray Hedging (Резервирование каналов)
Сетевое ядро Octopus поддерживает параллелизацию и взаимную страховку независимых сетевых лучей, исключая эффект Bufferbloat и предотвращая потерю пакетов. При сбоях на одном маршруте пакеты гарантированно доставляются по альтернативному каналу.

4. Адаптивная автокалибровка MTU
Встроенный механизм динамического зондирования непрерывно определяет оптимальный размер MTU внутри туннеля для конкретного провайдера, предотвращая фрагментацию пакетов и падение пропускной способности.


КЛЮЧЕВЫЕ ВОЗМОЖНОСТИ:
• Низкий отклик: прямая маршрутизация без лишних промежуточных узлов, оптимизированная для сетевых приложений и игр.
• Высокая пропускная способность: асинхронный сетевой стек и оптимизированные кольцевые буферы.
• Защита в публичных сетях: надежное шифрование данных при подключении через общественные точки доступа Wi-Fi.
• Подключение в один клик: удобное управление без необходимости ручной настройки профилей.
• Гибкая тарификация: учет фактического времени использования без скрытых автосписаний.
